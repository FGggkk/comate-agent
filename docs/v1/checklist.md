## 实现完整性

### 后端

- [ ] **T1 脚手架**：`docker compose up -d` 后 PostgreSQL 可连接，后端 `uvicorn app.main:app` 启动无报错
- [ ] **T2 配置**：后端启动日志打印配置概览（不暴露密码），config.yaml + 环境变量覆盖正常
- [ ] **T3 数据库模型**：所有 SQLAlchemy 模型定义可导入，`memory_items` 含 `embedding Vector(1536)` 字段
- [ ] **T4 邮箱验证码**：调用 `POST /api/auth/send-code` → 邮箱收到 6 位验证码；调用 `POST /api/auth/verify-code` → 返回 JWT token；5 分钟后验证码失效
- [ ] **T5 SOUL 系统**：`GET /api/souls/templates` 返回 5 个模板；`POST /api/souls/recommend` 返回 2 个推荐含 match_score；`POST /api/souls/preview` 返回 2-3 轮对话；`POST /api/users/me/soul` 保存成功
- [ ] **T6 记忆服务**：写入记忆 → 语义搜索可召回 → 删除后不再召回；禁区话题在搜索结果中被过滤；添加禁区 → Agent 不再主动提及；添加未完待续锚点 → 下次对话返回锚点信息
- [ ] **T7 模型网关**：`stream("你好")` 逐 token 输出；`chat("你好")` 返回完整文本；API 超时或错误时返回错误消息（不崩溃）
- [ ] **T8 编排引擎**：发送一条消息 → SSE 事件序列为 `status → [memory_card] → text_chunk... → action_buttons → done`，顺序正确
- [ ] **T9 对话 API**：`POST /api/chat/send` 返回 `text/event-stream`；`GET /api/chat/history` 返回最近 50 条消息
- [ ] **T10 面试场景**：输入简历 → 基线面试出 3-5 题 → 第二轮覆盖历史问题 ≥ 90% → 第三轮检查复发 → 生成报告含问题列表 + 改善趋势
- [ ] **T11 提醒服务**：创建提醒 → 查询列表 → 到期提醒被正确返回

### 前端

- [ ] **T12 前端框架**：`npm run dev` 启动显示登录页；未登录无法访问主界面
- [ ] **T13 前端 API**：6 个 API 模块请求/响应在 Network 面板可观察，状态码正确
- [ ] **T14 登录 + SOUL 选择**：输入邮箱 → 收验证码 → 登录成功（新手走 SOUL 选择，老用户直接进对话）
- [ ] **T15 对话页**：发消息 → 依次看到状态指示器 → 记忆卡片 → 文字逐段出现 → 快捷按钮 → 流结束
- [ ] **T16 记忆页**：三层记忆分开展示 → 共建层可编辑/删除 → 禁区锚点可添加/解除 → 未完待续锚点可标记完成
- [ ] **T17 面试 + 设置页**：面试全流程可走通，报告正确展示；设置页展示当前 SOUL 和提醒列表

### 部署

- [ ] **T18 集成部署**：`docker compose up` → 浏览器访问 → 注册 → 选 SOUL → 对话 → 记忆 → 面试全流程无阻断

## 端到端场景

### 场景 1：新用户完整旅程

操作步骤：
1. 打开页面 → 看到登录页
2. 输入邮箱 → 点击"发送验证码"
3. 查看邮箱 → 获取 6 位验证码
4. 输入验证码 → 点击登录
5. （首次登录）进入 SOUL 选择 → 偏好测试 5 题
6. 看到 2 个推荐 SOUL → 选择一个 → 预览 2-3 轮对话
7. 确认 → 进入对话页
8. 输入"我下周要面试，有点紧张" → 发送
9. 观察：状态指示器 → 记忆卡片"这是我们的第一次对话" → 文字流 → 快捷按钮

预期结果：新手在 5 分钟内完成注册→选 SOUL→首次对话。

### 场景 2：老用户连续使用

操作步骤：
1. 登录（不经过 SOUL 选择）→ 直接进入对话页
2. 对话页看到上次最后几条消息
3. 发送"上次聊的面试准备" → Agent 引用未完待续锚点
4. 切换到记忆页 → 看到三层记忆有数据
5. 编辑一条共建层记忆 → 保存成功
6. 删除一条记忆 → 确认删除
7. 切换回对话页 → 发送相同内容 → Agent 不再引用已删除记忆

预期结果：记忆持续存在，删除后不引用，锚点自动续接。

### 场景 3：禁区管理

操作步骤：
1. 发送"别再跟我提健身的事了"
2. 切换到记忆页 → 禁区锚点区域出现"健身"条目（红色标签）
3. 切换回对话页 → 发送"我最近状态怎么样"
4. Agent 回复不包含健身相关内容
5. 切换到记忆页 → 解除禁区
6. 再问"我最近状态怎么样" → Agent 正常回复包含健身情况

预期结果：禁区设置后 Agent 绝不触碰，解除后恢复正常。

### 场景 4：面试全流程

操作步骤：
1. 切换到面试页（Tab）
2. 输入简历文本："3 年前端开发经验，熟悉 Vue/React，做过 2 个大型项目"
3. 输入目标岗位："高级前端工程师，字节跳动"
4. 点击"开始面试"
5. 回答第一题 → 看到评估反馈
6. 回答第二题 → ...直到所有题目完成
7. 点击"生成报告"
8. 报告展示：问题列表 + 回答记录 + 改善趋势

预期结果：面试闭环完整，报告可查阅。

### 场景 5：提醒功能

操作步骤：
1. 切换到设置页
2. 创建提醒："明天下午 3 点面试准备"
3. 切换到对话页 → 到时间后页面内弹出提醒消息
4. 切换到设置页 → 看到提醒列表
5. 取消提醒 → 列表刷新

预期结果：提醒按时触发，可管理。

### 场景 6：响应式布局

操作步骤：
1. 在手机宽度（375px）浏览器打开 → 全宽显示
2. 在平板宽度（768px）浏览器打开 → 居中显示
3. 在桌面宽度（1440px）浏览器打开 → 居中 max-w 768px
4. 切换 4 个 Tab，各页面正常显示

预期结果：一套代码，三端自适应。
