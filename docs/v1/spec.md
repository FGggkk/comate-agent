# 伴行agent v1 — Spec

## 背景

已完成伴行agent的产品设计、技术方案和 8 周执行计划。现进入开发阶段。第一期 v1 的目标是：

- 用户可选 SOUL → 日常陪伴 → 长期记忆 → 连续面试场景
- 前后端分离：Vue 3（前端）+ FastAPI（后端）+ PostgreSQL/pgvector（数据层）
- 消息采用 B+C 融合模式：后端多步骤内部编排，前端逐步骤渲染

## 目标

| # | 目标 | 说明 |
|---|------|------|
| G1 | 用户注册 / SOUL 选择 / 开始对话 | 完整的 onboarding 流程 |
| G2 | 日常对话（基于 SOUL 人格） | 每次对话使用用户选择的 SOUL 身份 |
| G3 | 长期记忆（三层架构） | 先验层 / 共建层 / 默契层 + 禁区锚点 + 未完待续锚点 |
| G4 | 主动提醒 | 用户设定提醒事项，到时触发 |
| G5 | 连续面试场景（简化版） | 简历上传 → 基线面试 → 两轮训练 → 报告 |
| G6 | 记忆管理页面 | 查看 / 确认 / 修改 / 删除记忆 + 管理禁区 + 管理锚点 |
| G7 | 响应式 Web UI | 手机和电脑共用一套界面，只做右侧聊天区域 |

## 功能需求

### F1：用户注册与登录

| ID | 需求 | 说明 |
|----|------|------|
| F1.1 | 用户输入邮箱，点击"发送验证码" | 后端生成 6 位随机数字验证码 |
| F1.2 | 后端通过配置的邮箱发送验证码到用户邮箱 | 发件人凭据在配置文件中管理 |
| F1.3 | 用户输入验证码，校验通过即登录/注册 | 同一接口，验证码有效期 5 分钟 |
| F1.4 | 首次验证通过自动创建账号 | 免去额外注册步骤 |
| F1.5 | 登录后进入 SOUL 选择流程 | 首次登录走 onboarding，之后直接进对话页 |

### F2：日常对话

| ID | 需求 | 说明 |
|----|------|------|
| F2.1 | 用户输入文字消息，发送后流式接收回复 | SSE 逐 token 返回 |
| F2.2 | 每次对话使用用户当前 SOUL 作为身份 Prompt | 人格一致性 |
| F2.3 | 请求链路经过：安全 → 加载 SOUL → 读记忆 → 路由 → 模型 → 安全检查 | B+C 多步骤 |
| F2.4 | 前端按步骤展示：状态指示 → 记忆卡片 → 文字流 → 快捷操作按钮 | 逐步渲染 |
| F2.5 | 对话历史可滚动查看 | 加载最近的 50 条消息 |
| F2.6 | 输入框支持 Enter 发送 | 无语音输入，v1 纯文字 |

### F3：长期记忆（三层架构 + 锚点）

| ID | 需求 | 说明 |
|----|------|------|
| F3.1 | 先验层：系统预置信息，不主动在对话中引用 | 知道但不等于可以说 |
| F3.2 | 共建层：用户主动告诉或确认的记忆，可查看/编辑/删除 | 核心信任层 |
| F3.3 | 默契层：从交互中自然沉淀的推断，标记为"推断"来源 | 需要可解释路径 |
| F3.4 | 禁区锚点：用户明示"不要再提"的话题，Agent 绝不主动触碰 | 绝对遵守 |
| F3.5 | 未完待续锚点：上次聊一半的事，下次对话主动续上（保质期 3-7 天） | 续接感 |
| F3.6 | 记忆页面：可视化三层 + 禁区 + 未完待续，支持编辑和删除 | 独立 Tab |

### F4：主动提醒

| ID | 需求 | 说明 |
|----|------|------|
| F4.1 | 用户可设定提醒（时间 + 内容） | 面试前提醒、日常事项 |
| F4.2 | 到时间后在对话页内弹出提醒消息 | 模拟推送，不做真推送 |
| F4.3 | 用户可查看/取消已设定的提醒 | 管理页面 |

### F5：连续面试场景

| ID | 需求 | 说明 |
|----|------|------|
| F5.1 | 用户输入简历内容（纯文本） | v1 只支持文本输入 |
| F5.2 | 输入岗位描述或目标公司 | 基线面试据此出题 |
| F5.3 | 基线面试：系统出 3-5 题，用户逐题回答 | 记录每个问题的回答 |
| F5.4 | 第二次训练：重点复测基线中未解决的问题 | 覆盖 ≥ 90% 历史问题 |
| F5.5 | 第三次训练：压力追问，检查是否复发 | 记录改善趋势 |
| F5.6 | 面试报告：问题列表 + 回答 + 改善趋势 | 可视化展示 |

### F6：记忆管理页面

| ID | 需求 | 说明 |
|----|------|------|
| F6.1 | 分层展示所有记忆（先验/共建/默契） | 用标签区分层级 |
| F6.2 | 共建层可编辑内容 / 删除 | 底部操作按钮 |
| F6.3 | 显示禁区锚点（红色标签）和未完待续锚点（绿色标签） | 独立区域 |
| F6.4 | 可添加/解除禁区 | 用户主动管理 |

### F7：UI 与响应式

| ID | 需求 | 说明 |
|----|------|------|
| F7.1 | 只显示右侧聊天区域，无左侧导航 | 仅聊天界面 |
| F7.2 | 手机端全宽，PC 端居中 max-w 768px | 一套代码自适应 |
| F7.3 | 底部 TabBar 切换：聊聊 / 记忆 / 面试 / 设置 | 4 个 Tab |
| F7.4 | 消息气泡：用户气泡 + Agent 气泡（含角色头像） | 视觉区分 |

## 非功能需求

| ID | 需求 | 说明 |
|----|------|------|
| N1 | 响应式布局 | 手机全宽，PC 端居中 max-w 768px，Tailwind 一套代码 |
| N2 | SSE 流式响应 | 后端逐步返回，前端逐段渲染 |
| N3 | 验证码有效期 5 分钟 | 过期自动失效，60 秒后可重新发送 |
| N4 | 对话历史至少保留最近 50 条 | 按时间倒序读取 |
| N5 | SOUL 跨用户隔离 | 每个用户独立 SOUL 版本，串用为 0 |
| N6 | 记忆删除后同步清除向量索引 | 删除覆盖关系型 + pgvector |
| N7 | 前端 Vue 3 + Vite + Tailwind，后端 FastAPI + PostgreSQL/pgvector | 技术栈锁定 |
| N8 | 所有交互记录 Trace 日志 | 用于排查和审计 |

|--------|------|

| 语音输入 / 语音播报 | 纯文字版 |
| 自定义 SOUL（维度滑块 + 自由文本） | 只用 5 种内置模板 |
| SOUL 历史版本恢复 | v1.1 |
| 成长时间线 / 周报 | v1.1 |
| Hermes 在线调用 / 离线学习 | v1.1 核心功能 |
| 考研搭子 / 口语场景 | 只做连续面试 |
| 真推送通知 | 只在页面内模拟提醒 |
| 图片 / 文件上传 | 简历用纯文本输入 |

## 验收标准

| AC | 对应需求 | 验收方式 |
|----|---------|----------|
| AC1 | F1 | 输入邮箱 → 收到验证码 → 输入验证码 → 进入 SOUL 选择 |
| AC2 | F1 | 同一邮箱再次输入验证码 → 直接登录（无需重新选 SOUL） |
| AC3 | F2 | 发送消息 → 前端依次显示"思考中"→ 记忆卡片 → 文字流 → 快捷按钮 |
| AC4 | F2 | 刷新页面后对话历史不丢失 |
| AC5 | F3 | 用户说"我下周面试"→ 下次对话 Agent 正确提到 |
| AC6 | F3 | 用户删除记忆 → 之后对话再不引用该内容 |
| AC7 | F3 | 用户设禁区"别提前任"→ Agent 在任何场景下不主动提 |
| AC8 | F3 | 用户说"改天聊聊旅行"→ 下次对话 Agent 主动续上（保质期内） |
| AC9 | F4 | 设定提醒 → 到时间对话页内弹出提醒消息 |
| AC10 | F5 | 输入简历 → 基线面试出题 → 第二轮覆盖首轮问题 → 第三轮检查复发 → 生成报告 |
| AC11 | F6 | 记忆页展示三层 + 禁区 + 锚点，可编辑/删除 |
| AC12 | F7 | 手机浏览器全宽显示，PC 浏览器居中 768px，Tab 切换正常 |
