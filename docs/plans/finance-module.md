# 记账模块设计方案

## 一、页面结构

工作台 → 点击「记账」→ 进入记账页（两个标签页）

```
┌─────────────────────────────┐
│ ← 返回工作台                │
│                             │
│  [💬 会话]  [📊 账单]       │
│                             │
│      (标签内容)             │
└─────────────────────────────┘
```

## 二、💬 会话标签页

AI 对话式记账：用户发消息「中午吃饭花了32」，AI 自动识别金额、分类、时间
返回确认卡片让用户确认/修改/取消
消息历史保留所有记账对话记录

## 三、📊 账单标签页

### 功能分区
1. 月度概览卡片（毛玻璃效果）：当月结余、收入/支出对比、环比增减
2. 收支列表（按日期分组）：图标+分类+备注+金额，左滑删除，点击编辑
3. 分类统计：各分类占比+彩色进度条
4. 「💰记一笔」浮动按钮 → 底部弹出面板

### 底部弹出面板
金额输入、收支切换、分类横向滚动选择、备注输入、保存/取消

## 四、分类体系（8个）

🍜餐饮 🚕交通 🛒购物 🏠居住 🎮娱乐 📌其他支出 💰薪资 📦其他收入

## 五、设计要点

收入绿 #5FBE63 / 支出橙 #FF9F45 / 背景暖白
等宽数字、卡片微阴影、spring弹出动画、列表过渡动画、毛玻璃卡片

## 六、数据模型

FinanceRecord { id, user_id, type(income/expense), category, amount(分), note, record_date, created_at, source(ai/manual) }

## 七、后端 API

POST /api/finance/record       — 新增
GET  /api/finance/records      — 列表（按月筛选）
PUT  /api/finance/record/:id   — 修改
DELETE /api/finance/record/:id — 删除
POST /api/finance/ai-parse     — AI解析自然语言
GET  /api/finance/summary      — 月度汇总

## 八、执行任务

P0 — 基础框架: 数据库模型+CRUD API + FinancePage双标签 + 工作台入口
P1 — 账单标签: 月度概览+收支列表+分类统计+记一笔面板
P2 — 会话标签: AI对话记账+确认卡片+后端AI解析接口+数据同步
P3 — 交互打磨: spring动画+列表过渡+数字滚动+毛玻璃
