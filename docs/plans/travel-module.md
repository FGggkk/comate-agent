# 旅游规划模块 — 设计方案

## 一、页面流程

```
工作台 → 点击「旅游规划」
    │
    ▼
┌──────────────────────────────┐
│ ← 返回工作台                  │
│                               │
│  [📝 规划]  [📋 历史]         │ ← 双标签
│                               │
└──────────────────────────────┘
```

## 二、双标签结构

### 📝 规划标签

**两步流程：**

**Step 1 — 填写需求（混合输入）**

```
┌──────────────────────────────┐
│ 目的地: [________]  *必填     │
│ 出发日期: [____]  [____]     │ ← 日期选择器
│ 天数: [3]天                   │
│ 预算: [5000]元               │
│ 人数: [2]大 [0]小            │
│ 偏好: 自然风光 / 美食 / 文化  │ ← 多选标签
│       购物 / 休闲 / 冒险      │
│ 备注: [________________]     │
│                               │
│  [🤖 AI 生成行程]             │
└──────────────────────────────┘
```

**Step 2 — 行程展示（卡片式日程）**

```
┌──────────────────────────────┐
│ ← 重新填写                     │
│                               │
│  📍 北京 · 3天 · 预算¥5000    │ ← 行程概览头
│  💰 预算明细: 住宿¥1800       │
│             餐饮¥1200 门票¥800 │
│                               │
│  ┌── 第1天 · 7月28日(一) ──┐ │
│  │  ☀️ 上午 故宫博物院     │ │
│  │     门票¥60 建议2h      │ │
│  │  ⛅ 下午 景山公园→南锣  │ │
│  │  🌙 晚上 王府井小吃街   │ │
│  │  [修改这天] [不满意]    │ │ ← 单独操作
│  └──────────────────────────┘ │
│                               │
│  ┌── 第2天 · 7月29日(二) ──┐ │
│  │  ☀️ 上午 八达岭长城     │ │
│  │  ⛅ 下午 鸟巢/水立方     │ │
│  │  🌙 晚上 簋街           │ │
│  │  [修改这天] [不满意]    │ │
│  └──────────────────────────┘ │
│                               │
│  [📄 导出] [💾 收藏此方案]    │
└──────────────────────────────┘
```

**操作能力：**
- 点击某天的「修改这天」→ AI 单独重新生成那天
- 点击「不满意」→ 重新生成那天
- 顶部「重新填写」→ 回到 Step 1 改参数
- 「导出」→ 复制/下载文本
- 「收藏」→ 保存到历史

## 三、数据模型

```
TravelPlan {
  id: UUID
  user_id: UUID (FK)
  title: string (如"北京3日游")
  destination: string
  start_date: date
  days: int
  budget: int (分)
  adults: int (默认1)
  children: int (默认0)
  preferences: string[] (标签)
  note: string
  saved: bool (是否收藏)
  created_at: timestamp
  updated_at: timestamp
}

TravelDay {
  id: UUID
  plan_id: UUID (FK)
  day_number: int
  date: date
  segments: jsonb ([
    { period: "morning"|"afternoon"|"evening",
      title: string,
      description: string,
      cost: int,
      duration: string,
      tips: string }
  ])
  total_cost: int
}

TravelBudget {
  accommodation: int
  food: int
  tickets: int
  transport: int
  other: int
}
```

## 四、后端 API

```
POST   /api/travel/plan          — AI 生成行程
GET    /api/travel/plans         — 获取历史列表
GET    /api/travel/plan/:id      — 获取某个行程详情
PUT    /api/travel/plan/:id      — 更新（收藏/重命名）
DELETE /api/travel/plan/:id      — 删除
POST   /api/travel/plan/:id/regenerate-day — 重新生成某天
POST   /api/travel/plan/:id/regenerate     — 调整参数后重生成
```

## 五、AI 生成流程

```
用户提交表单
  → 拼接 prompt（目的地/天数/预算/人数/偏好）
  → 调用 DeepSeek
  → 返回结构化 JSON（每天行程 + 预算明细）
  → 解析后存入数据库
  → 前端渲染卡片
```

**Prompt 示例：**
```
你是一个旅游规划专家。根据以下信息制定详细行程：

目的地：北京
天数：3天
预算：5000元
人数：2成人
偏好：自然风光、美食
出发日期：2026-07-28

要求：
1. 按天输出，每天分上午/下午/晚上三个时段
2. 每项活动包含：标题、描述、预估费用、建议时长、小贴士
3. 输出JSON格式
4. 最后输出总预算明细（住宿/餐饮/门票/交通/其他）
```

## 六、执行任务

P0 — 基础框架：数据模型 + 迁移SQL + 后端 API + TravelPage 双标签 + 工作台入口
P1 — 规划标签：表单输入 + AI 生成 + 卡片行程展示 + 单天修改
P2 — 历史标签：历史列表 + 收藏管理 + 删除
P3 — 交互打磨：导出 / 动画 / 预算可视化
